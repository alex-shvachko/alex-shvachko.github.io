# Archived robot scene

This folder preserves the robot-and-nature hero scene removed from the live first page on 2026-09-26.

It contains the scene entry point and modules, the Three.js runtime and loaders, all models loaded by the scene, its robot fallback image, and the site stylesheet used to size and present the scene. The archived scripts expect to be served from this folder so their original relative asset paths resolve.

To restore the scene for review, temporarily serve this folder as the site root and use the original scene markup from the repository history. The active root `index.html` is intentionally blank for now.
